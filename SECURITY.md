# Security Policy

## Responsible use

`s_vdet` is a network reconnaissance and vulnerability-matching tool. It is
built for:
- Auditing systems and networks you own
- Security testing with explicit, documented authorization
- Lab environments, CTFs, and training exercises

**Do not use this tool against systems you do not own or lack explicit
written permission to test.** Unauthorized scanning may violate computer
misuse laws in your jurisdiction (e.g. the CFAA in the US, the Computer
Misuse Act in the UK). `s_vdet` shows an authorization prompt before every
scan for this reason - it is a speed bump, not a legal safeguard, and the
responsibility for lawful use rests with the operator.
